Dúvidas

Preciso de internet?

Só para instalar. Depois funciona sem internet.

Onde ficam meus dados?

Somente no seu celular. Por isso é importante baixar o backup de vez em quando: se trocar de aparelho ou limpar os dados do navegador, sem backup eles se perdem.

Funciona no iPhone e no Android?

Sim. No Android pelo Chrome, no iPhone pelo Safari, usando “Adicionar à tela de início”.

Substitui o contador?

Não. O Meu Painel do Dono dá indicadores simples a partir do que você lança. Não é orientação contábil nem fiscal.

Posso migrar do Básico para o Avançado?

Sim. Baixe o backup no Básico e restaure no Avançado: os lançamentos vêm junto.
